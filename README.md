## 🌟 概要

Gemini APIを活用した空間認識・オブジェクト検出アプリケーションです。指定した画像に対して、各種Geminiモデルを使用してオブジェクト検出と空間理解を行います。

このアプリケーションを使用することで、以下のことが可能になります：
- 画像内のオブジェクトを自動検出し、バウンディングボックスで可視化
- さまざまなGemini 2.0モデルのパフォーマンスを比較
- カスタムプロンプトによる特定オブジェクトの検出
- 多言語での検出結果の表示

## 🚀 機能

- **複数モデル対応**: Gemini 2.0の各種モデル（flash, flash-lite, pro）での推論をサポート
- **カスタムプロンプト**: 自由にプロンプトを設定して特定オブジェクトの検出が可能
- **カテゴリ分類されたサンプル画像**: 
  - 🍽️ **食べ物・料理**: お弁当、フルーツ、カップケーキなど
  - 🏞️ **自然・動物**: 猫、カボチャなど
  - 🏙️ **都市・生活**: 本棚、靴下、折り紙など
- **ユーザー画像**: 自分の画像をアップロードして分析可能
- **バウンディングボックス可視化**: 検出されたオブジェクトを視覚的に表示
- **日本語対応**: 日本語での操作と結果表示

## 💻 インストール方法

1. リポジトリをクローン
```bash
git clone https://github.com/yourusername/SpatialVision-Gemini-Bench.git
cd SpatialVision-Gemini-Bench
```

2. 必要なパッケージをインストール
```bash
pip install -r requirements.txt
```

3. 環境変数の設定（オプション）
```bash
echo "GOOGLE_API_KEY=あなたのAPIキー" > .env
```

## 🔧 使用方法

1. アプリケーションを起動
```bash
streamlit run app.py
```

2. ブラウザでアプリケーションを開く（通常は http://localhost:8501）

3. サイドバーでGemini APIキーを入力（.envファイルに保存していない場合）

4. 使用するモデルと検出設定を選択

5. 画像カテゴリを選択し、サンプル画像を選ぶか、自分の画像をアップロード

6. 「オブジェクト検出を実行」ボタンをクリック

## 📊 結果の解釈

- **バウンディングボックス**: 検出されたオブジェクトを色付きの枠で表示します
- **ラベル**: 各オブジェクトに付与された説明または分類
- **JSON出力**: APIからの生のレスポンスを確認可能

## 📝 プロンプトの例

- **基本検出**: "画像内のすべてのオブジェクトを検出"
- **特定オブジェクト**: "赤い靴下だけを検出"
- **詳細説明**: "食べ物を検出し、日本語と英語で説明"
- **特性検出**: "最も熟している果物を検出"

## 📂 画像カテゴリ

アプリケーションには以下のカテゴリのサンプル画像が含まれています：

1. 🍽️ **食べ物・料理**
   - お弁当、フルーツ、カップケーキ、野菜、朝食

2. 🏞️ **自然・動物**
   - 猫、カボチャ

3. 🏙️ **都市・生活**
   - 本棚、靴下、折り紙、こぼれたコーヒー

各カテゴリには、それぞれの画像に適したサンプルプロンプトが用意されています。

## ⚠️ 注意事項

- 有効なGemini APIキーが必要です
- 大きな画像は自動的にリサイズされます（最大1024px）
- 検出結果はモデルやプロンプトによって異なる場合があります
